1. Recharge API POST / GET
Request :
https://your-domain.example/webservices/api/recharge?username=[username]&api_token=[api_token]&number=[number]&amount=[amount]&operator=[operator_code]&ref_id=[your_ref_id]
Response (in JSON) : 
{"status":"Accepted","number":"9999999999","amount":"10","operator":"VF","ref_id":"ABC1","txn_id":"123456","opt_id":"ABCDEFGH12345","balance":"100.00","message":"Recharge request accepted."}
Request Pramaters List
PARAMETER DESCRIPTION
username Your registered mobile number with us
api_token APIKEY generated in profile section Get API Token
number Recharge number / DTH Connection number
amount Recharge Amount
operator Operator code Get Operator Codes
ref_id Unique transaction id generated from your server/website
Response Pramaters List
PARAMETER DESCRIPTION
status
Pending : When we have successfully accepted your recharge request.
Accepted : When we have successfully accepted your recharge request.
Success : When your recharge processed successfully.
Failure : When your recharge is failed / rejected by operator.
Refunded : When we have refunded your recharge.
Error : When your request has some wrong data. You can consider it as FAILURE only for RECHARGE API
NOTE: DO NOT CONSIDER AS FAILURE IN STATUS CHECK API
number Recharge mobile number / DTH connection number
amount Recharge Amount
operator Operator code (Visit Website -> API Configuration -> Operator Code List)
ref_id Unique transaction id generated from your server/website
txn_id Unique ID generated by Exchange
opt_id Unique reference id generated by Operator
balance Closing balance after this recharge
message A simple string which shows error message.

Response (in JSON) : 
{"status":"Success","dispute_id":"DISP-883921","ref_id":"ABC1","message":"Dispute ticket raised successfully"}
Request Pramaters List
PARAMETER DESCRIPTION
username Your registered mobile number with us
api_token APIKEY generated in profile section
ref_id Unique transaction id generated from your server/website
reason Reason for dispute / complaint (e.g. AMOUNT_NOT_CREDITED)
Response Pramaters List
PARAMETER DESCRIPTION
status Success : Dispute registered successfully under review.
dispute_id Unique complaint / dispute ticket reference ID.
ref_id Your unique transaction reference ID.
message Dispute confirmation message.
5. Callback / Webhook URL POST
Callback Notification : Sent to your Webhook URL
POST request sent by Exchange to your callback endpoint upon final transaction status.
Payload (in JSON) : 
{"status":"Success","number":"9999999999","amount":"10","operator":"VF","ref_id":"ABC1","txn_id":"123456","opt_id":"ABCDEFGH12345","balance":"100.00","message":"Recharge successful"}
Callback Pramaters List
PARAMETER DESCRIPTION
status Final transaction outcome status (Success or Failure).
number Recharged mobile / DTH account number.
amount Recharge amount in INR.
operator Operator code.
ref_id Your unique transaction reference ID.
txn_id Exchange system transaction ID.
opt_id Operator reference ID.
balance Updated wallet closing balance.
Your Server Response

Your webhook receiver must return HTTP 200 OK with JSON:

{"status":"OK"}

7. API Response Codes & Error List SPECIFICATION

Standard HTTP and application-level response codes returned by the Buyer API:

CODE STATUS RESPONSE MESSAGE & DESCRIPTION
235 SUCCESS SUCCESS- Dispute Accepcted — Dispute request registered and accepted.
106 FAILED FAILED- Account Suspended -Contact To Admin — Buyer user account is suspended.
109 FAILED FAILED- Duplicate Reference Id — A transaction with this reference ID already exists.
128 FAILED FAILED- Insufficient Fund — Insufficient INR balance in buyer wallet.
142 FAILED FAILED- Mobile length should be between {Min-Max} — Mobile number length does not match operator required length.
145 FAILED FAILED- Invalid API key — Username or API token is missing, incorrect, or invalid.
160 FAILED FAILED- No sellers available for selected margin — No seller matches or satisfies buyer configured purchase margin limit.
242 FAILED FAILED- Bad Voucher or This Denomination Is Not Allowed — Denomination outside operator limits or marked as stopped.
270 FAILED FAILED- Service has been temporarily suspended for Your account for more detail contact to customer care — Service access is temporarily suspended.
