# Error Code API Status Category API Response Message Detailed Reason & Recommended Solution
1 145 FAILED Auth & Security FAILED- Invalid API key Invalid Credentials: Registered username or api_token is missing, incorrect, or regenerated.
Solution: Copy your active API token from IP Setting / API Document page.
2 106 FAILED Auth & Security FAILED- Account Suspended -Contact To Admin Account Suspended: User account is marked as suspended by Administrator.
Solution: Contact support / administration desk to reactivate your account.
3 270 FAILED Auth & Security FAILED- Service has been temporarily suspended for Your account Service Blocked / Inactive: Account is blocked or service temporarily disabled (or inactive due to prolonged inactivity).
Solution: Reach out to customer care to verify KYC and re-enable API service.
4 107 FAILED Auth & Security FAILED- IP not whitelisted Unauthorized Server IP: API request arrived from an IP address not approved in your whitelist.
Solution: Add your outgoing server static IPv4 address under Setting → IP Setting.
5 ERR_RATE_LIMITED FAILURE Auth & Security Too many requests; rate limit exceeded Rate Limit Exceeded (HTTP 429): Burst requests per minute exceeded allowed API quota (Recharge / Status / Balance).
Solution: Use webhooks/callbacks instead of aggressive status polling, and throttle traffic smoothly.
6 ERR_INVALID_NUMBER FAILURE Recharge Validation Invalid mobile or account number Malformed Subscriber Number: Recharge number parameter is empty or contains invalid characters.
Solution: Pass numeric subscriber ID / mobile number without spaces or symbols.
7 142 FAILED Recharge Validation FAILED- Mobile length should be between {Min-Max} Invalid Number Digit Length: Mobile or DTH subscriber number length does not match operator's permitted digit count.
Solution: Verify 10-digit mobile or operator-specific DTH/Utility subscriber ID length before calling API.
8 ERR_INVALID_AMOUNT FAILURE Recharge Validation Invalid recharge amount Invalid Amount Parameter: Amount is missing, ≤ 0, non-numeric, or has invalid decimal formatting.
Solution: Send a valid positive amount in INR (e.g. 299 or 199.00).
9 242 FAILED Recharge Validation FAILED- Bad Voucher or This Denomination Is Not Allowed Denomination / Plan Restricted: Requested amount is below operator minimum, above maximum limit, or listed in blocked/stopped denominations.
Solution: Check valid recharge plans and operator min/max amount slab.
10 ERR_INVALID_OPERATOR FAILURE Operator Config Operator code is required or could not be determined Missing Operator Parameter: Request lacks the operator code parameter.
Solution: Include valid operator code (e.g. AIRTEL, JIO, VI, BSNL).
11 ERR_OPERATOR_NOT_FOUND FAILURE Operator Config Operator code is not registered or active Unrecognized Operator Code: Passed operator code does not match any active operator in platform.
Solution: Query /webservices/api/operators or refer to the Operator Code table in API Docs.
12 161 FAILED Operator Config invalid circle Unresolved Telecom Circle: Specified circle code or name could not be matched to a valid Indian telecom circle.
Solution: Pass standard circle name/code or leave optional to auto-detect.
13 160 FAILED Routing & Stock FAILED- No sellers available for selected margin No Eligible Seller Available: Either all sellers for this operator/circle failed in waterfall routing, have insufficient stock/balance, or your Buyer Margin expectation is higher than active seller offers.
Solution: Adjust your expected margin under Buyer → Buyer Margin or retry after a short interval.
14 ERR_MISSING_REF_ID FAILURE Duplicate Check Unique ref_id is required Missing Idempotency Reference: Request is missing client-generated ref_id.
Solution: Always send a globally unique alphanumeric ref_id for every recharge attempt.
15 109 FAILED Duplicate Check FAILED- Duplicate Reference Id Duplicate Transaction Ref ID: A recharge order with this ref_id has already been recorded under your account.
Solution: Generate a fresh unique ref_id for new transactions; use Status Check API for existing ones.
16 110 FAILED Duplicate Check FAILED- Same number and amount was already processed recently Duplicate Guard Triggered: Identical number + amount recharge submitted within repeat throttle window.
Solution: Wait for duplicate window cooldown or verify previous transaction status before retrying.
17 128 FAILED Wallet Balance FAILED- Insufficient Fund Insufficient Wallet Balance: Usable balance in your Buyer Wallet (or Unified Wallet minus active lien) is lower than debit required.
Solution: Submit a Wallet Topup Request or transfer funds from Seller Wallet to Buyer Wallet.
18 ERR_WALLET_NOT_FOUND FAILURE Wallet Balance Wallet account not found Missing Wallet Ledger: Active INR wallet record could not be located for user account.
Solution: Contact Administrator to initialize wallet record.
19 ERR_MISSING_PARAM FAILURE Status / Dispute Parameter ref_id or recharge_id is required Missing Order Identifier: Neither ref_id nor recharge_id was supplied in query/body.
Solution: Pass at least one valid transaction reference parameter.
20 ERR_NOT_FOUND FAILURE Status / Dispute Transaction not found for the given ref_id Order Not Found: No transaction exists matching the supplied ref_id or recharge_id under your account.
Solution: Verify reference ID spelling and ownership.
21 111 FAILED Dispute Rules FAILED- This transaction has already been refunded/failed Already Refunded / Failed: Disputes cannot be filed against transactions that have already failed or been refunded.
Solution: Amount has already been returned to your Buyer Wallet.
22 114 FAILED Dispute Rules FAILED- A dispute is already pending review Dispute Already Submitted: An active dispute ticket is already logged and awaiting review for this transaction.
Solution: Check dispute status under Buyer → Recharge Dispute.
23 112 FAILED Dispute Rules FAILED- Complaints cannot be accepted after validity period Dispute Window Expired: Allowed time limit (in hours/days configured by Admin) to file a dispute has elapsed.
Solution: Raise complaints promptly within the active SLA window.
24 113 FAILED Dispute Rules FAILED- Complain can only be submitted after minimum wait time Too Soon to Dispute: Minimum waiting minutes after transaction completion have not passed yet.
Solution: Wait the required cooldown interval and resubmit complaint.
25 ERR_CALL FAILURE Upstream / System Failed to communicate with supplier API Supplier Gateway Unreachable / Timeout: Network error or timeout occurred when forwarding request to upstream seller API. Waterfall engine automatically cascades to next available seller.
Solution: Check Status API if order remains pending; failed orders auto-refund.
26 EMPTY_RESPONSE FAILURE Upstream / System Supplier API returned an empty response Empty Upstream Payload: Seller API closed connection or sent an empty HTTP body.
Solution: System automatically routes to fallback seller or refunds buyer balance.
27 HTML_ERROR_PAGE FAILURE Upstream / System Supplier API returned an HTML error page Invalid Upstream Response Format: Seller endpoint returned HTML (e.g. 502/503/404 page) instead of expected JSON/XML.
Solution: Request automatically fails over to secondary seller in waterfall.
28 ERR_SERVICE_UNAVAILABLE FAILURE Operator Lookup Plan API / Operator Lookup service is not enabled Lookup Gateway Inactive: Operator auto-detection service is disabled or credentials missing.
Solution: Pass explicit operator code in recharge API call or contact admin.
29 ERR_SERVER FAILURE System Error Internal server error processing request Unexpected Exception (HTTP 500): Server encountered an unexpected processing condition.
Solution: Always verify status via Status Check API using your ref_id before retrying.
30 0 SUCCESS Success / Accepted Recharge request accepted / Transaction Details Retrieved Request Processed Successfully: Returned for successful Recharge, Pending Accepted, Status Check, Balance Check, and Operator Lookup.
Note: Inspect status field (SUCCESS / PENDING / FAILURE) for final recharge result.
31 235 SUCCESS Dispute Accepted SUCCESS- Dispute Accepcted Dispute Ticket Registered: Complaint accepted and escalated for supplier/admin verification.
Outcome will be delivered via callback webhook and Dispute report.
