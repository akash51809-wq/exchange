Zendash - Admin Dashboard HTML Template

Folder Structure

assets/
						├── css/
						|   | |-- animated.css
						|   | |-- sidemenu.css
						|   | |-- sidemenu.scss
						|   | |-- sidemenu.map
						|   | |-- dark.scss
						|   | |-- dark.map
						|   | |-- dark.css
						|   | |-- icons.css
						|   | |-- skins.css
						|   | |-- skins.scss
						|   | |-- skins.map
						|   | |-- style.css
						|   | |-- style.map
						├── iconfonts/
						├── images/
						├── js/
						├── plugins/
						├──  scss/
  • Zendash - Admin Dashboard HTML Template / : Root template folder contain all html, js, css, scss, images and other files.
  • assets/ : Folder contain all the Admin Template assets which has css, js, scss, and images.
    • css/: Folder contain assets which has sample scss, css, js files.
      • verticalmenu/ : verticalmenu folder contain sidemenu css.
      • animated : animate.css contains animations css like fadein, fadeout, rotate etc.
      • icons : icons.css has all template icons link are importated.
      • skins : skins.css has external styles for template.
      • style : Main style sheet for template.
      • dark : Darktheme css for the template.
    • img/ : Template images.
    • js/ : Folder contain all the template pages js files.
    • plugins/ : Folder contain all template plugins.
    • scss/ : Folder contain all pages scss files.
  • gulpfile.js : Gulp tasks js file.
  • package.gulp.json : Gulp package json file.
